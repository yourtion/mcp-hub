# MCP Hub 前端功能测试计划

## 测试概述

本计划旨在使用 chrome-devtools 工具对 MCP Hub 前端进行全面的功能测试,覆盖所有核心功能的创建、修改、删除操作,确保系统功能正常工作。

## 测试环境准备

### 启动服务
- [ ] 启动后端服务: `pnpm dev:api` (localhost:8181)
- [ ] 启动前端服务: `pnpm dev:fe` (localhost:8180)
- [ ] 使用 chrome-devtools 打开前端页面

### 测试凭证
- 用户名: `admin`
- 密码: `admin`

## 测试执行计划

### 执行策略
1. **顺序执行**: 按照测试组顺序依次执行
2. **待办跟踪**: 每完成一项测试,在对应项前打勾 ✅
3. **问题记录**: 发现问题时记录详细信息
4. **截图存证**: 关键步骤和问题点截图保存

### 执行流程
1. **环境准备** → 启动服务,准备测试环境
2. **登录测试** → 确保能正常登录系统
3. **功能测试** → 按组依次测试各功能模块
4. **结果汇总** → 统计测试结果,生成报告

### SubAgent 分组
为提高效率,将测试分为多个并行组:

**并行组1 (基础功能)**
- SubAgent 1: 登录认证测试
- SubAgent 2: 仪表板功能测试

**并行组2 (核心管理)**
- SubAgent 3: 服务器管理测试
- SubAgent 4: 工具管理测试
- SubAgent 5: 组管理测试

**并行组3 (高级功能)**
- SubAgent 6: API到MCP管理测试
- SubAgent 7: 调试工具测试
- SubAgent 8: 系统配置测试
